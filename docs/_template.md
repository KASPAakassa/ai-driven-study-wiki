# 文章模板

> 每篇 Wiki 文章遵循统一结构(参考 Karpathy 教学风格:概念 → 原理 → 代码 → 实践)。
> 新建文章时复制本文件,按 `###` 层级填写;用不上的小节可以留空 `<!-- 待补充 -->`。

---

# 标题(一句话讲清本文主题)

> **一句话摘要**:本文讲什么、解决什么问题、为什么值得读。
>
> **来源**:原文链接 / 出处(必须填写,便于追溯)

## 概念

- 这个主题是什么?核心定义。
- 为什么重要?解决什么问题?
- 相关概念对比(如有)。

## 原理

- 底层机制如何工作,拆成步骤讲清楚。
- 配图/公式/流程图(如适用)。
- 关键点与常见误解。

## 代码 / 实现

```python
# 最小可运行示例 / 核心实现片段
```

- 逐段解释关键代码。
- 运行方式与依赖。

## 实践 / 应用

- 真实场景中怎么用?工程要点?
- 性能、成本、注意事项、坑。

## 总结

- 用 3-5 个要点回顾本文。
- 下一步学什么(给出方向)。

## 延伸阅读

- 关联 Wiki 文章(站内链接)
- 外部资料(论文、博客、课程)
