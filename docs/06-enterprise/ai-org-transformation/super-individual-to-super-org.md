# 从超级个体到超级组织:李志飞的组织转型拆解

> **一句话摘要**:出门问问 CEO 李志飞 2025 年用 Cursor 三天写出近 20 万行代码(「AI 版飞书」原型),随后发现"个人真的很累,公司完全跟不上",花近一年推动组织转型:自研 CodeBanana 组织操作系统、用 Agent 替代中间管理层、全员全栈化。本文拆解这场"从超级个体到超级组织"的转型全过程与认知心法。
>
> **来源**:腾讯研究院《AI跃迁者调研》第五期(嘉宾:李志飞/余一/袁晓辉),https://mp.weixin.qq.com/s/ywS4Vx2hDdq0BhJbU2CCzw;原文存档于 `docs/inbox/ai-org-transformation-source.md`

!!! note "归类说明"
    本文属于 **AI 组织转型与超级个体** 子主题(管理者/组织视角的认知与方法论),与 FDE(交付方法论)、AI Friendly 架构(系统工程)是不同维度——详见 [子主题首页](index.md) 的区分说明。

## 金句洞察(先记住这六句)

1. **超级个体的价值被高估,超级组织的价值被低估**;
2. **AI 的产能是无限的,但所有的瓶颈都在于人**——人多的壁垒,接下来会变成负债;
3. **打造超级组织,你真的要有所谓的延迟满足感**;
4. **任务在哪里,沟通就应该在哪里**——未来绝大部分人,包括 CEO,某种程度上都是在配合 AI 干活;
5. **真正强的超级个体,是你自己对这个世界有很强烈的想法,能设计一套游戏规则,再把它固化到系统里**;
6. **一个有价值的生态系统,一定成就个人也成就集体**。不转是必死无疑的;转不一定能够过得很好,但转是必须动作。

## 一、超级个体:AI 产能无限,瓶颈全在人

**背景**:李志飞(机器翻译 PhD、Google Translate 背景,2012 年创业做语音助手/智能手表/AI 配音)2025 年 6 月"三天近 20 万行代码"做出 AI 版飞书原型——此前近 10 年没编过程序,靠 AI + Cursor 一个人覆盖前端/后端/算法/UI/商业模式。

**但他很快碰到天花板**:

- **个人真的很累**:时间有限;
- **公司完全跟不上**:组织执行力是瓶颈。

!!! tip "瓶颈的本质"
    "AI 想要什么就给你什么,但**「你想要什么」要靠人想、靠人判断**。"意图带宽有限、思考能力有限、判断能力有限——**产能无限,瓶颈在人**。几个聪明人习惯一致、商业/产品/研发各有强项,再把 AI 产能发挥出来,价值是单个超级个体的好多倍。

## 二、工作流革命:从线性流水线到原型驱动

AI 带来的最大组织变化,是工作流从**线性**变成**原型驱动**:

| 维度 | 线性流水线(旧) | 原型驱动(新) |
| --- | --- | --- |
| 流程 | 老板需求 → 产品调研 → 设计交互 → 前后端测试联调 | 开会 → 会议文档扔给 AI → **直接出原型** |
| 人力 | 按工种分工、中间管理层多 | 绝大部分人全栈化,结构极度扁平 |
| 中间层 | 只做沟通的岗位存在 | 只做沟通的人要么能抽象到战略/组织设计,要么能具象到第一线干活 |

**案例**:发布会前一个周末,李志飞两天每天 10 小时,一个人完成 60 页可线上演示的 HTML 宽屏 PPT(含 20 多个产品视频位);同事熬一晚,就做出了第二天 6 场系列发布会。

## 三、CodeBanana:任务在哪里,沟通就在哪里

### 问题:两类工作被拆在不同工具里

- **管理沟通**(开会、项目管理、CEO 宣讲)→ 飞书/企业微信;
- **任务执行**(写代码、做交付)→ Cursor/Claude。

CodeBanana 要做的是**沟通与执行合二为一**——这是《超级组织》"沟通发生在哪里,执行就发生在哪里"理念的产品化落地。

### 系统形态(三个区域 + Agent 当正式员工)

```
CodeBanana(界面类似飞书,但每个项目同时是群聊 + Agent 工作空间 + 共享文件系统)
├── discussion     :人类聊天
├── Team Agent     :共享 Coding Agent
└── private ask    :先私聊再公开
每个项目:自己的虚拟机 + 权限
```

- **Agent 被当作正式员工**:有 A2A 通讯、Skill 商店、Teams.md 通讯录、Dashboard 量化指标;
- **公司所有人全部运行在这个系统上,没有例外**;
- 系统转起来后,CEO 每天的工作也被 AI 驱动:"由人发起,AI 再驱动人反馈,很难分清到底谁指挥谁"——**未来绝大部分人包括 CEO,都在配合 AI 干活**。

!!! tip "与知识库的呼应"
    这与 [Agent 即正式队友](../../08-harness/multica.md)(Multica 看板派单)是同一理念的不同实现:一个面向团队协作平台,一个自研组织操作系统;任务与沟通合一 = [Subagent](../../03-agents/subagent-isolation.md) 语境下"任务契约随沟通流转"的组织级版本。

## 四、全栈转型铁律:威逼、工具、筛选

出门问问的组织转型,李志飞概括为「**威逼利诱,更多是威逼**」。2025 年 8 月给产研团队定了几条原则:

1. **不分工种,必须全栈**;
2. **不允许手写一行代码**;
3. **不允许自己跑命令行**(改个变量名也要跟 Agent 说);
4. **不允许用编辑器**。

一个月后**每人重新面试**:半小时做出以前一星期的活,题目随机。结果:主动离开 + 优化约 **20%-30%**,基本没再补人。产研团队 2025 年 12 月已全部全栈化。

!!! warning "决策逻辑"
    先上**统一上下文的协作系统,让系统筛选人**——纠结"先裁员还是先转型"意义不大。CEO 要有信仰、有手感,某种程度上还得有点「**独裁**」才能推极端转型。

## 五、系统设计师:把控制权还给需求方

2026 年,李志飞给非产研负责人提了更高标准:**你必须成为系统设计师**——底层 Infra 已搭好(建项目/建群/拉人/A2A 通讯/自动化心跳/Skill 积木块),用积木搭自己的系统:

- 销售负责人自己写了一套 **CRM**(dashboard + 知识库 + Skill);
- HR 能上线**招聘网站**;
- KOL 负责人做了整套**运营系统**。

以前这些活都要"求爹告娘找产研";现在**控制权还给了需求方**。有意思的是:**非产研反而用得比产研更好**——门槛比 Cursor 低,成就感极强。两周后每人面试:"你怎么运营小部门?AI 怎么参与?**不能指挥好 AI,就别做 leader。**"

## 六、延迟满足感:从个体到组织的桥

超级个体和超级组织最不一样的地方是**反馈速度**:

- **超级个体**:第一天就进入状态,正反馈极强(一个人 3 天搞出飞书);
- **超级组织**:初期全是摩擦力——"像一个人住宿舍很爽,跟 4 个人合租一开始各种不习惯,磨合好了体验非常好"。

**李志飞的管理短板,反而逼他找变量**:传统组织规模化靠人,他管不了 1000 人/1 万人,就想 AI 能不能成为公司最主要的执行力。2024 年下半年走访 40 个湖畔同学企业后认定:**管理是稀缺能力,他没有,那就绕开它**。

!!! warning "转型的时间代价"
    这条路没有捷径:自己做系统、比较独裁、老业务不大,转型用了**快 10 个月还没到终极形态**,绝大部分公司没有一年很难。

## 七、AI 跃迁十问要点(数据与判断)

| 问题 | 李志飞回答(要点) |
| --- | --- |
| 每天跟 AI 多久 | 至少 10 小时以上,80%+ 在 CodeBanana;开发布会前两天每天 10 小时做 60 页 PPT |
| 彻底改变的习惯 | **AI First**:打电话前先跟 AI 讨论;开会不临时拉人,先跟 AI 做文档;给员工的信经 Agent 加工、员工回的也全是 AI 发的 |
| Token 消耗 | 现在 <$1000/月(高峰期 $300/天);两三个月前 token 成本是人力成本 **15%**,人均 ~$2000/月,用最贵模型不设限(后收敛) |
| 必须重新思考的问题 | 组织内:**人跟 Agent 是什么关系、什么人该留下、人机交互系统怎么设计**;组织外:so what——AI 用好了是否真的产生商业价值、充分竞争后有没有生态位 |
| 最大的组织改变 | 工作流变革(线性 → 原型)+ 全栈化 + 极度扁平 |
| 组织与 AI 匹配度 | **6-7 分**——token 层面很疯狂,但"用好了是否真产生商业价值"存疑 |
| 最大挑战 | 延迟满足感(组织转型是集体行为,初期全是摩擦力) |
| 模型层变迁的意义 | 模型不是 focus;在做**基于模型和 Agent 框架的组织容器**——环境里有 人/Agent/部门/Skill/实体,模型变强驱动系统转得更快 |
| 被高估/低估 | 超级个体被高估,超级组织被低估 |
| 最坚定的信念 | **AGI 要有个体智能也有集体智能**,真正的 AGI 最好在组织环境下涌现出集体智能 |

## 实践 / 应用:可借鉴清单

1. **先想清楚"你想要什么"**:AI 产能无限,瓶颈是意图带宽——判断能力比执行能力更值钱(呼应 [FDE 崛起](../fde-methodology/fde-rising.md) 的"解决正确的问题");
2. **工作流优先于工具**:先改"线性 → 原型驱动"的协作方式,再谈工具(原型驱动 = 会议 → 文档 → AI 出原型);
3. **沟通与执行合一**:任务在哪里,沟通就在哪里——选择/建设支持"群聊 + Agent 工作区 + 文件系统"合一的组织系统;
4. **转型要"威逼 + 工具 + 筛选"**:立规矩(全栈/不手写代码)、上统一系统、用系统筛选人;
5. **把控制权还给需求方**:让业务人员用积木式 Infra 自建系统(系统设计师),而非事事求产研;
6. **接受延迟满足感**:组织转型没有捷径,做好"初期全是摩擦力"的心理准备,以年为单位推进;
7. **先问 so what**:AI 用得好 ≠ 商业价值,充分竞争下要有生态位意识。

## 总结

- **超级个体**:AI 产能无限、瓶颈在人(意图带宽);个人英雄主义越强,在组织里越难受;
- **工作流革命**:线性流水线 → 原型驱动,组织走向全栈化、扁平化;
- **CodeBanana** = 沟通与执行合一的组织操作系统,Agent 当正式员工(A2A/Skill 商店/Teams.md/Dashboard);
- **转型铁律**:威逼、工具、筛选;系统设计师把控制权还给需求方;
- **延迟满足感是从个体到组织的桥**;转型以年计,没有捷径;
- 核心信念:**超级个体被高估、超级组织被低估;AGI 应有集体智能**。
