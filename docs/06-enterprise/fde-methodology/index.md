## 预计覆盖方向

- **FDE 是什么**:角色定义、与售前/解决方案架构师/研发的区别、为什么 AI 时代 FDE 变得关键
- **能力模型**:技术(快速搭建、集成、调优)+ 业务(理解客户流程、识别痛点)+ 软技能(沟通、现场)
- **工作方法论**:进场 → 需求澄清 → 快速原型 → 交付 → 反馈闭环;原型驱动、以点带面
- **组织与协作**:FDE 与销售/产品/研发/客户的关系、规模化复制(从项目到产品)
- **案例与思考**:OpenAI 等公司的 FDE 实践、个人成长路径

## 学习指引

- 入门顺序:角色认知 → 能力模型 → 工作流 → 案例复盘。
