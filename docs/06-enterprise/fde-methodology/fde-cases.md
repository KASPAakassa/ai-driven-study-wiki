> **一句话摘要**:从 Palantir 到 OpenAI、Anthropic、Sierra、Decagon、Harvey 再到中国公司,本章汇总 FDE 的经典实践案例、后记中的六条职业底线,以及附录中的四层指标体系和人物名单。
>
> **来源**:《前线部署工程师》第 8 章 + 后记 + 附录(范冰,www.zengzhang.ai,2026 开源),全文存档于 `references/fde-book/book.txt`

## 案例集:五家标杆公司的 FDE 实践

### Palantir:开山鼻祖

- 起源:FDE 概念的诞生地,"只做客户付费的项目、客户永远正确、拥抱战斗"三原则(见 [FDE 崛起](fde-rising.md));
- 打法:Forward Deployed Engineer 深入政府/金融客户现场,与客户并肩作战;
- 启示:**深度嵌入客户业务 + 为结果负责**,是 FDE 的原型。

### OpenAI:技术先锋的交付实践

- 打法:技术能力展示(POC/MVD 化)+ 客户共创,用灯塔客户验证产品方向;
- 启示:**技术公司同样需要"问题猎手"**——先确认客户真实问题,再谈 API 接入(OpenAI 早期大量客户是"先 POC 后生产")。

### Anthropic:企业安全优先

- 打法:强调安全与合规(五张地图中的安全/法务通关),用"可信任"赢得企业客户;
- 启示:**结构信任是企业级 AI 的入场券**——安全、合规、透明度是 FDE 的必修课。

### Sierra / Decagon:垂直 AI 客服的样板

- Sierra(客服 Agent)/ Decagon(客服自动化):**把 AI 客服做到行业深度**,用可度量的客户成果(响应时间、解决率、成本)续约扩量;
- 启示:**垂直深耕 + 价值度量系统**是 AI 公司的典型增长路径——成果可量化,续约与扩量才有依据(呼应 [扩大收入](fde-revenue.md))。

### Harvey:法律 AI 的信任打法

- Harvey(法律 AI):高价值、高敏感场景,靠专业信任 + 结构信任(安全合规)拿下顶级律所;
- 启示:**行业知识密度越高,FDE 的价值越大**——FDE 必须成为"半个行业专家"才能赢得专业客户。

## 后记:FDE 的职业道德——六条底线

FDE 掌握客户数据与系统,是"带着镣铐跳舞"的信任角色。六条职业底线:

1. **诚实**:不夸大能力与效果,不为了签单过度承诺;
2. **隐私**:尊重客户数据,最小化收集、严格保密;
3. **克制**:只做该做的事,不越权、不滥用访问权限;
4. **知情**:改动客户系统/数据前,必须让客户知情同意;
5. **反盗版/合规**:不帮助客户做违法或侵权的事(如用盗版数据训练);
6. **行善**:技术应服务客户真实利益,而非单纯取悦付费方。

!!! warning "为什么职业道德是护城河"
    FDE 的核心资产是信任(见 [赢得客户](fde-acquisition.md) 的信任红利)。一次失信(数据泄露、越权操作、夸大效果)不仅毁掉单个客户,更会毁掉整个 FDE 的口碑——**道德底线是职业生命线**。

## 附录 A:FDE 常用指标(四层体系)

| 层级 | 指标 | 回答的问题 |
| --- | --- | --- |
| **交付层** | 交付周期、部署成功率、上线后缺陷率、热修复时效 | 我们交付得好吗? |
| **客户层** | 健康度、使用率、Quick Win 达成率、满意度、流失预警 | 客户在用吗?用得好吗? |
| **商业层** | 续约率、扩量率、价值兑现(ROI 证据)、NPS、转介绍率 | 客户为价值付费吗? |
| **组织层** | FDE 人均服务客户数、新人上手周期、手册覆盖率、方法论复用率 | FDE 体系能复制吗? |

!!! tip "指标的使用纪律"
    指标不是报表,是**决策输入**:交付层指标指导改进交付、客户层指标触发流失预警、商业层指标支撑定价与扩量、组织层指标衡量规模化进度——每一层都要"看了会行动",否则是数字装饰。

## 总结

- **案例启示**:Palantir(原型)、OpenAI(灯塔验证)、Anthropic(结构信任)、Sierra/Decagon(垂直 + 价值度量)、Harvey(行业深度)——FDE 打法在不同公司形态下的变体;
- **六条职业底线**:诚实、隐私、克制、知情、反盗版、行善——信任是 FDE 的生命线;
- **四层指标**:交付/客户/商业/组织,每层服务一个决策;
