# 扩大收入:从续约到增值,价值度量与成果计价

> **一句话摘要**:客户不流失只是及格,扩大收入才是增长。本章拆解免费验证、转换设计、成果计价、扩容路径、定价心理学与价值度量系统——让客户为"价值"而非"工时"付费。
>
> **来源**:《前线部署工程师》第 6 章(范冰,www.zengzhang.ai,2026 开源),全文存档于 `references/fde-book/book.txt`

## 收入扩大四阶梯

1. **续约**:守住存量(第 5 章);
2. **扩量**:同一客户用更多(更多部门、更多数据、更多功能);
3. **增值**:同一客户买更多(新模块、高级服务、定制);
4. **转介绍**:客户带来新客户(信任红利变现)。

!!! tip "扩收入的前提"
    扩大收入的底层是"价值可度量"——客户说不出"你到底给我创造了多少价值",就没有扩量的谈判基础。

## 免费验证:先给价值,再谈付费

- 对潜在扩量需求,**先免费小范围验证价值**(新部门试用、新场景试点),用结果说话;
- 免费验证 ≠ 无限白嫖:限定范围、限定时间、明确"验证成功后转付费";
- 逻辑与 [赢得客户](fde-acquisition.md) 的"免费做小东西"一致:**先让价值可见,付费是价值的自然结果**。

## 转换设计:从免费到付费的无痛衔接

- **转换设计** = 设计"免费体验 → 付费使用"的路径,减少阻力:
  - 免费版给"够用"的核心能力,付费版给"更省心/更强"的增量(功能分层);
  - 使用数据留存:客户用惯了免费版,数据与流程已绑定,转换成本自然升高;
  - 明确的升级触发点:当客户用满免费额度/功能时,恰到好处地提示升级。

## 成果计价:让价格绑定价值

- 传统计价(按时长/人数/功能)与客户价值脱钩——客户不知道"值不值";
- **成果计价(outcome-based pricing)**:价格与客户成果挂钩(如按节省的成本、新增的收入、处理的数量分成);
- 优点:客户无风险(没成果不付钱)、信任感强、收入随价值增长;
- 风险:需要**可靠的价值度量系统**(否则无法计算分成),且承担客户自身经营波动的风险。

!!! warning "成果计价的前提"
    没有可靠度量系统的成果计价 = 空头支票。先建价值度量系统(见下文),再谈按成果计价。

## 扩容:同一客户的价值空间

扩容路径(从低到高):

1. **横向扩部门**:从市场部扩展到销售/客服/研发;
2. **纵向扩场景**:从单一场景扩展到相关流程;
3. **数据扩量**:接入更多数据源,模型价值放大;
4. **能力扩级**:从辅助(Assist)升级到自动化执行(Agent 化)。

!!! tip "扩容的天然盟友"
    扩容量大的是客户内部**已经尝到甜头的用户**——他们是扩容需求的提出者(呼应 [组织维系](fde-retention.md) 的多角色渗透)。

## 定价心理学:FDE 也要懂的定价常识

- **锚定效应**:先给高方案,再给中方案——客户感受"中方案划算";
- **价值锚点**:报价先讲"你节省/创造了多少",再讲"我们收多少"(先价值后价格);
- **减少决策负担**:套餐不超过 3 档(经典:基础/标准/旗舰);
- **涨价的艺术**:老客户涨价要提前告知 + 给过渡期 + 说明新增价值,新客户直接新价。

!!! note "FDE 的角色"
    FDE 不背销售指标,但**定价信息的收集者与价值证据的提供者**——FDE 最清楚"客户到底赚了多少",这是定价谈判的第一手弹药。

## 价值度量系统:扩大收入的基石

**价值度量系统** = 一套持续量化"我们为客户创造了多少价值"的机制:

- **定义价值指标**:与客户业务挂钩(节省工时、降低成本、提升转化、规避风险);
- **基线测量**:部署前先测客户的基线水平(没有基线就没有增量);
- **持续跟踪**:部署后定期测量,生成价值报告;
- **归因清晰**:明确哪些改善来自 AI(排除季节性/其他因素)。

!!! tip "价值报告的作用"
    价值报告不只是给客户看的"成绩单",更是续约谈判、涨价谈判、成果计价、案例营销的**统一证据来源**——一个系统,支撑整个商业闭环。

## 总结

- 扩收入四阶梯:续约 → 扩量 → 增值 → 转介绍;
- **免费验证**先给价值,再谈付费;转换设计减少免费→付费阻力;
- **成果计价**绑定价值但有前提——必须有可靠的价值度量系统;
- **扩容路径**:横扩部门、纵扩场景、数据扩量、能力扩级;
- **定价心理学**:锚定、价值锚点、三档套餐、涨价艺术;
- **价值度量系统**是扩大收入的基石:基线 → 跟踪 → 价值报告,支撑整个商业闭环。
