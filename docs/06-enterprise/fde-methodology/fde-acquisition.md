# 赢得客户:灯塔客户、笨办法与信任红利

> **一句话摘要**:AI 公司如何赢得第一批客户?不是靠广告和销售话术,而是靠**灯塔客户 + 笨办法 + 信任红利**。本章拆解从找到第一个付费客户到完成提案、签约、安全合规通关的全过程。
>
> **来源**:《前线部署工程师》第 3 章(范冰,www.zengzhang.ai,2026 开源),全文存档于 `references/fde-book/book.txt`

## 灯塔客户:第一个客户决定一切

- **灯塔客户** = 愿意承担早期不确定性、与你共同打磨产品的第一个标杆客户;
- 选择标准:影响力大、痛点真实、愿意深度配合(给数据、给现场、给反馈);
- 目的:不是赚第一笔钱,而是**打造可复制的成功样本**——后续所有客户都向灯塔看齐;
- **灯塔失败 = 全盘皆输**:第一个客户做砸,修复信任的成本是建立信任的十倍。

!!! tip "与 POC 的关系"
    灯塔客户是"MVD 打动人之后,愿意付钱进入正式合作"的那批人——先过 [PSF 三关](fde-problem.md),再谈灯塔。

## 笨办法:AI 公司早期获客的真相

作者给出残酷的现实:**早期的"聪明"营销都不如笨办法有效**。笨办法三层递进:

1. **第一层:创始人/团队亲自下现场**——见客户、听抱怨、做 demo,拿到一手反馈;
2. **第二层:给客户免费做点小东西**——先交付一个低成本高价值的小工具,建立信任(免费的东西最能撬动开口);
3. **第三层:把自己变成内容**——写文章、做分享,把解决问题的思路公开,吸引同频客户(内容营销的本质是"提前展示你会怎么解决我的问题")。

!!! warning "为什么不用销售大军"
    早期产品未定型,销售话术是"空头支票";笨办法贵在**让客户直接看到你的能力和诚意**——信任红利一旦建立,后续销售成本骤降。

## 需求蝗虫:识别"看起来像机会"的陷阱

AI 公司会被大量"需求"淹没,作者提醒区分:

- **伪需求**:客户嘴上说痛、实际不痛(过了 PSF 问题关才知道);
- **毒需求**:需求真实但会把团队拖进泥潭(小客户、大定制、低回报);
- **黄金需求**:痛点真实、预算明确、可复制。

!!! tip "FDE 的过滤器"
    面对扑面而来的需求,用 [PSF 三关](fde-problem.md) + "可复制性"双重过滤:**单点需求救急,可复制需求才值得投入**。

## 信任红利:客户为什么选你

AI 公司卖的不是"技术",是**信任**。信任红利的三个来源:

1. **专业信任**:你能解决他解决不了的问题(专业能力可见);
2. **人格信任**:你靠谱、不忽悠、说到做到(笨办法与亲自下现场建立);
3. **结构信任**:你的流程、安全、合规让客户放心长期合作(见下文采购/法务/安全)。

!!! note "信任的复利"
    信任红利是**复利资产**:第一次合作建立的信任,会降低第二次合作的摩擦、带来转介绍、容忍小失误。相反,一次失信(过度承诺、数据泄露)会瞬间清零。

## 五张地图:打进客户组织的导航

在客户组织内部,不同角色关注点不同,要分别建立"地图":

| 地图 | 对象 | 关注点 |
| --- | --- | --- |
| 决策地图 | 高层决策者 | ROI、战略价值、风险 |
| 采购地图 | 采购部门 | 流程、价格、合规 |
| 法务地图 | 法务 | 合同条款、数据权属、责任 |
| 安全地图 | 安全/IT | 数据安全、接入风险、审计 |
| 用户地图 | 一线使用者 | 好用、省事、不添乱 |

!!! tip "为什么重要"
    一个客户内部有多个否决点——技术负责人认可,采购卡价格;采购通过,法务卡条款。**五张地图 = 识别每个角色最在意什么,分别攻破**。

## 采购、法务、安全:三大通关项

- **采购通关**:报价透明、流程配合、有合同模板——降低客户的"买你"的摩擦力;
- **法务通关**:数据权属清晰、责任边界明确、合规条款完备(尤其数据敏感的行业);
- **安全通关**:安全架构说明、渗透测试报告、合规认证(等保/SOC2 等)——**没有安全,再好的技术也进不了大客户**。

!!! warning "最容易被忽略的通关"
    技术团队常常忽略采购/法务/安全,而这恰恰是 AI 公司死在"最后一公里"的头号原因——客户认可技术,但走不完内部流程。

## 生态捆绑与开源工具:借力获客

- **生态捆绑**:与大平台/渠道合作,借对方的客户资源(如接某个云市场、与集成商合作);
- **开源工具**:开源一部分能力,吸引开发者试用,再引导到商业产品——**开源是技术公司的低成本获客漏斗**;
- 两者的共同逻辑:**降低客户"试你"的门槛**,把"从零信任"变成"先用了再说"。

## 排期与提案:赢单的临门一脚

- **排期艺术**:高峰期资源有限,把最强的 FDE 排给最关键的灯塔客户;宁可少接,不可做砸;
- **提案结构(倒金字塔)**:先结论(我们能帮你解决什么问题、多少钱、多久),再展开细节(方案、团队、里程碑)——**决策者没时间看长文档**;
- **混合交付模式**:纯定制太重、纯产品太僵,**"产品 + 定制"混合**是 AI 服务的主流形态(见 [扩大收入](fde-revenue.md) 的转换设计)。

## 出海:FDE 的全球化副本

- 出海客户同样需要"灯塔 + 笨办法 + 信任红利"——本地化团队、时区协作、合规(数据出境)是额外功课;
- 文化差异影响谈判与交付节奏,需要本地化的 FDE(或本地伙伴);
- 出海的第一原则:**先证明在一个市场跑通,再复制**,与"灯塔客户"逻辑一致。

## 总结

- **灯塔客户决定一切**:第一个客户要选影响力大、痛点真实、愿深度配合的;
- **笨办法三层**:亲自下现场、免费做小东西、把自己变成内容——早期获客没有捷径;
- **需求过滤**:伪需求、毒需求、黄金需求要分清,可复制性优先;
- **信任红利**:专业信任 + 人格信任 + 结构信任,是复利资产;
- **五张地图 + 采购/法务/安全通关**是打进大客户组织的必修课;
- **生态捆绑、开源工具、排期、倒金字塔提案、混合交付**共同构成赢单闭环。
