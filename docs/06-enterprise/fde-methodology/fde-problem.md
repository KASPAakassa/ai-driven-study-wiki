# 解决正确的问题:PSF 三关、拒绝 POC 坟墓与 MVD 军规

> **一句话摘要**:FDE 工作的第一步不是写代码,而是**确认自己在解决正确的问题**。本章拆解 PSF(产品-市场匹配)三关、POC 坟墓的三道防线、影子工作法、MVD 三条军规与训练营五动作。
>
> **来源**:《前线部署工程师》第 2 章(范冰,www.zengzhang.ai,2026 开源),全文存档于 `references/fde-book/book.txt`

## 核心命题:多数失败是做对了错误的事

!!! warning "最常见的死法"
    大量 AI 项目死于"高效地解决了错误的问题":POC 做得漂亮但客户不买账、采购驱动的项目没人用、想当然的解决方案根本没对上真需求。**"解决正确的问题"永远先于"高效解决问题"**——这也是 FDE 区别于"会写代码的人"的第一道分水岭。

## PSF 三关:问题被确认前的三道检查

在动手前,FDE 必须确认三件事(缺一不可):

| 关 | 问题 | 通过的标准 |
| --- | --- | --- |
| **问题关** | 客户是否**认可**这是问题? | 客户亲口承认痛点、有真实场景与损失 |
| **客户关** | 客户是否**认可你**? | 建立信任,客户愿意跟你深入协作 |
| **预算关** | 客户是否有**预算/愿意付费**? | 有资金或有明确付费意愿(付费是最强验证) |

!!! tip "为什么是'三关'而非'一问'"
    客户说"我们确实有这个痛点"不算过关——他可能只是礼貌;要等到**他愿意投入时间、数据、甚至预算**才算。付费是唯一不会撒谎的验证信号。

## 拒绝 POC 坟墓:POC 是把双刃剑

**POC(Proof of Concept)** 本意是快速验证,但现实中大量项目死在"POC 完成 → 客户没了下文"——作者称之为 **POC 坟墓**。三道防线:

1. **防线一:先谈"为什么要做"再谈"做什么"**——POC 之前先确认问题、客户、预算三关,否则 POC 只是自嗨;
2. **防线二:POC 前谈好"下一步"**——约定"如果 POC 成功,接下来做什么(试点/付费)",防止验收即终点;
3. **防线三:控制 POC 周期与投入**——用最小成本、最短时间验证最关键假设(见 MVD)。

!!! warning "POC 陷阱的本质"
    客户想要的不是"你能做出一个 demo",而是"我的问题能被解决"。POC 若被当作"展示技术"而非"验证解决路径",就必然掉进坟墓。

## 影子工作法:从"客户说的"到"客户真实做的"

客户说的需求往往是"想要的解决方案",而不是"真实问题"。**影子工作法(shadowing)**:FDE 像影子一样跟随客户真实工作流程,观察、记录、提问,把"客户声称的流程"和"实际发生的流程"对照,从中挖出真实痛点与改进机会。

!!! tip "价值"
    客户描述的需求带主观滤镜;影子工作看到的是**事实**。真实流程中的摩擦点(重复劳动、信息断裂、人工检查)才是 FDE 的切入点——也是"赢得客户"章节中"笨办法"(亲自下现场)的延续。

## MVD 三条军规:让 demo 打动客户

MVD(Most Valuable Demo)= 客户真正觉得有价值的演示,三条军规:

1. **军规一:不炫技**——重点不是展示技术多强,而是**展示问题被解决**;
2. **军规二:站在客户立场**——用客户的业务语言、客户的数据、客户的场景做 demo;
3. **军规三:让客户"哦"出来**——演示要击中客户内心"这正是我要的"的那个瞬间。

!!! note "与 POC 的区别"
    POC 验证"方案能不能行";MVD 打动"客户要不要买"。POC 是工程问题,MVD 是说服问题。好的 FDE 两者都要做,但明确各自目的。

## 训练营:五个动作,一周内快速切入新客户

FDE 面对新客户/新行业,靠"训练营"快速建立领域认知与信任:

1. **阅读**:行业报告、客户公开资料、竞品材料;
2. **访谈**:客户内部关键角色一对一,收集真实需求与抱怨;
3. **观察**:下现场,看真实流程(影子工作法);
4. **动手**:亲手做一个小工具/小改进,让客户看到"你能干活";
5. **复盘**:把训练营发现整理成问题清单,与客户对齐优先级。

!!! tip "训练营的目的"
    不是"学完再开工",而是**边学边创造价值**——一周内既建立领域理解,又给客户交付第一个"看得见"的东西,为后续激活建立信任基础。

## 总结

- 核心命题:**先解决正确的问题,再高效解决问题**;
- **PSF 三关**:问题关(客户认可)、客户关(客户认可你)、预算关(愿意付费)——付费是最强验证;
- **POC 坟墓**:先谈为什么、约定下一步、控制投入,三道防线防"验收即终点";
- **影子工作法**:看客户真实流程,挖真实痛点;
- **MVD 军规**:不炫技、站客户立场、让客户"哦"出来;
- **训练营五动作**:阅读、访谈、观察、动手、复盘。
