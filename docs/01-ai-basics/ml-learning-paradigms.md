# 机器学习的学习范式与核心概念:监督、无监督、强化学习

> **一句话摘要**:机器学习三种学习范式的定义与例子,以及贯穿所有 ML 任务的六个核心概念:数据集划分、训练/推理、过拟合、评估指标。
>
> **来源**:综合公开资料,参见文末延伸阅读。

## 概念

### 三种学习范式

根据训练时"手里有什么信息",机器学习分为三大类:

| 范式 | 训练数据 | 目标 | 典型任务 | 例子 |
| --- | --- | --- | --- | --- |
| **监督学习** | 输入 `x` + 标签 `y` | 学出 `x → y` 的映射 | 分类、回归 | 垃圾邮件识别、房价预测 |
| **无监督学习** | 只有输入 `x` | 发现数据内在结构 | 聚类、降维、异常检测 | 客户分群、数据可视化 |
| **强化学习** | 无标签,有奖励信号 | 学策略最大化累计奖励 | 决策、控制 | AlphaGo、机器人控制 |

- **监督学习(Supervised Learning)**:数据带"标准答案"。分类(输出离散类别,如"垃圾/正常")和回归(输出连续数值,如"房价 300 万")是两大子问题。
- **无监督学习(Unsupervised Learning)**:数据没有答案,算法自己找结构。聚类(把相似样本归为一组)、降维(把高维数据压缩到低维保留主要信息,如 PCA)。
- **强化学习(Reinforcement Learning, RL)**:智能体(agent)与环境交互,每一步行动得到**奖励(reward)**,目标是学习一个**策略(policy)**让长期累计奖励最大。它不是"喂答案",而是"试错 + 奖励"。

!!! note "半监督学习"
    现实中大量数据没有标签。**半监督学习**利用少量有标签 + 大量无标签数据;**自监督学习**(如大模型的"预测下一个词")从数据自身构造标签——这两类在今天的大模型时代成为主角(详见 [大语言模型章节](../02-llm/index.md))。

## 原理:六个必须懂的核心概念

### 1. 数据集划分:训练集 / 验证集 / 测试集

把数据分成三份,各司其职:

- **训练集(train)**:用来**拟合模型参数**(让模型学会)。
- **验证集(validation)**:训练过程中用来**调超参数、选模型**(防止把验证集"记住")。
- **测试集(test)**:训练全部结束后,**只测一次**,模拟真实新数据,检验泛化能力。

!!! warning "黄金规则"
    测试集是"期末考卷",只能最后用一次。反复用测试集调参等于把答案背下来,分数会失真。这也是"数据泄漏(data leakage)"最常见的一种。

### 2. 训练 vs 推理

- **训练(training)**:在训练集上通过优化算法更新参数,目标是让损失函数最小。
- **推理(inference)**:模型训练好后,用**固定参数**对新输入做预测。推理要快、要稳,训练要准。

### 3. 泛化、欠拟合与过拟合

- **泛化(generalization)**:模型在**没见过的数据**上表现好的能力——ML 的真正目标。
- **欠拟合(underfitting)**:模型太简单,训练集上都学不好(偏差高)。
- **过拟合(overfitting)**:模型太复杂,把训练集的**噪声也背了下来**,训练集表现极好、新数据表现差(方差高)。

```
训练误差高、验证误差也高  →  欠拟合(加复杂度)
训练误差低、验证误差高    →  过拟合(正则化/加数据/简化模型)
```

### 4. 评估指标:分类

以二分类(正/负)为例,先定义混淆矩阵:

|  | 预测为正 | 预测为负 |
| --- | --- | --- |
| **实际为正** | TP(真阳性) | FN(假阴性) |
| **实际为负** | FP(假阳性) | TN(真阴性) |

- **准确率 Accuracy** = (TP+TN)/总数 —— 类别均衡时好用,不均衡时会被"多数类"欺骗。
- **精确率 Precision** = TP/(TP+FP) —— "预测为正的里面有多少是对的",关注**误报**。
- **召回率 Recall** = TP/(TP+FN) —— "真正的正例里找回了多少",关注**漏报**。
- **F1** = 2·P·R/(P+R) —— 精确率与召回率的调和平均,均衡场景常用。
- **AUC(ROC 曲线下面积)** —— 综合衡量排序能力,对类别不均衡不敏感。

!!! tip "怎么选"
    癌症筛查要**高召回**(漏一个都危险);搜索结果要**高精确率**(别给用户垃圾结果);均衡场景看 **F1**。

### 5. 评估指标:回归

- **MSE(均方误差)** = mean((ŷ-y)²) —— 惩罚大误差,量纲是平方。
- **MAE(平均绝对误差)** = mean(|ŷ-y|) —— 对异常值更鲁棒。
- **R²(决定系数)** —— 模型解释了多大比例的数据方差,越接近 1 越好。

### 6. 偏差-方差权衡

- **偏差(bias)**:模型对真实规律的假设偏离程度(欠拟合来源)。
- **方差(variance)**:模型对训练集波动的敏感程度(过拟合来源)。
- 总误差 ≈ 偏差² + 方差 + 噪声。调参的本质就是在**偏差与方差之间找平衡点**。

## 代码 / 实现

用纯 Python 实现最核心的评估指标,理解它们怎么算:

```python
def classification_metrics(y_true, y_pred):
    tp = sum(1 for t, p in zip(y_true, y_pred) if t == 1 and p == 1)
    fp = sum(1 for t, p in zip(y_true, y_pred) if t == 0 and p == 1)
    fn = sum(1 for t, p in zip(y_true, y_pred) if t == 1 and p == 0)
    tn = sum(1 for t, p in zip(y_true, y_pred) if t == 0 and p == 0)

    acc  = (tp + tn) / len(y_true)
    prec = tp / (tp + fp) if tp + fp else 0.0
    rec  = tp / (tp + fn) if tp + fn else 0.0
    f1   = 2 * prec * rec / (prec + rec) if prec + rec else 0.0
    return {"Accuracy": acc, "Precision": prec, "Recall": rec, "F1": f1}

# 例子:100 个样本里 10 个是垃圾邮件,模型全判成正常 → 准确率 90% 但召回 0
y_true = [0] * 90 + [1] * 10
y_pred = [0] * 100
print(classification_metrics(y_true, y_pred))
# {'Accuracy': 0.9, 'Precision': 0.0, 'Recall': 0.0, 'F1': 0.0}
```

**关键点**:准确率 90% 看起来很漂亮,但垃圾邮件**一封都没抓出来**——这就是"类别不均衡时不能只看准确率"的活教材。

## 实践:一套完整的建模流程

一个标准 ML 项目的骨架(后面所有实战都会复用):

1. **理解问题**:分类还是回归?业务上更在乎漏报还是误报?
2. **数据准备**:清洗缺失值、处理异常值、划分训练/验证/测试集。
3. **特征工程**:选择/构造特征,做归一化(详见 [线性回归](ml-linear-models.md) 中的特征缩放)。
4. **选基线模型**:先跑一个简单模型(如逻辑回归)拿到基线分数。
5. **迭代优化**:加复杂度、调超参数,用**验证集**对比,警惕过拟合。
6. **最终评估**:只在测试集上评估一次,记录并交付。

## 总结

- 三种范式:**监督**(有答案)、**无监督**(没答案找结构)、**强化**(试错拿奖励)。
- 数据要分三份:训练/验证/测试,测试集只用一次。
- 过拟合 = 背下训练集噪声;欠拟合 = 太简单学不会;目标是在偏差与方差间平衡。
- 分类看 Accuracy/Precision/Recall/F1/AUC,**不均衡数据别只看准确率**;回归看 MSE/MAE/R²。
