先说结论。这一年半我跟进了 40 多家 50-200 人公司的 agent 项目，落地失败的原因九成不在技术，在
筛选
，筛错了岗位、筛错了任务、筛错了组织土壤。

我不打算讲 demo 到生产的那些技术鸿沟（那些工程细节别人已经讲得很好了），只讲从项目视角能看到的三个信号。掉进任何一个，agent 都很难跑起来。

信号一，把不该给 agent 的活儿交给了 agent

一个岗位或任务能不能交给 agent，用三个筛子。

频次
：一周做 3 次以上的重复动作才划算，低频活儿调 prompt 的时间够人做十遍

- 
明确性
：输入输出可以被结构化描述，"整理客户反馈"不算，"从记录里抽投诉类别、产品、情绪等级"才算

- 
容错性
：错一次不会造成不可逆损失，财报盖章、合同定稿这种不该是首个 agent 化对象

三筛都过的活儿，agent 能做。三筛不过的活儿，硬做就是拿钱打水漂。
