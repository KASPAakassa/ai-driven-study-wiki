# 数据抓取 / 分析经验记录 playbook

## 何时触发

用户说"记录一下这次抓取/分析经验"、"记一笔"、"这个坑记下来",或完成了一次**值得沉淀**的数据获取/解析/分析工作(尤其是踩过坑、找到了绕行方案、或发现了可复用技巧)时,执行本 skill。

## 目标

把一次性的经验沉淀为**下次可直接复用**的笔记:别人(未来的你或 agent)遇到同类任务时,不必重新踩坑。

## 执行步骤

1. **判断值得记吗**:满足任一即可记录——踩坑并找到绕行方案;用了非显而易见的技巧(如绕反爬、编码处理、特定解析策略);产出可复用代码片段;验证过某个结论/阈值/限制。
2. **追加到经验笔记**:读取 `docs/07-agent-coding/experience/data-scraping-notes.md`,按下面模板**追加**一条(不要覆盖已有条目,按日期顺序追加在文件末尾)。
3. **保持可检索**:标题用中文短语概括场景;`标签` 行至少含一个可检索关键词(如 `微信抓取`、`反爬`、`编码`、`解析`)。同一主题的条目可以互相引用(如"见 #12")。
4. **如产生可复用脚本**:超过 20 行的通用脚本建议放到 `tools/` 或独立文件,笔记里留链接;短片段直接内联在笔记代码块里。

## 记录模板

```markdown
### YYYY-MM-DD [N]:<一句话标题(场景+结论)>

- **场景**:做什么任务、数据源是什么(URL/接口/文件)、当时环境
- **方法**:怎么做的——关键命令、代码、工具链
- **坑**:遇到什么问题、症状是什么
- **解法**:怎么绕过的、为什么有效
- **可复用**:下次遇到同类任务可以直接抄什么(片段/命令/检查项)
- **标签**: `关键词1` `关键词2`
```

## 示例条目

```markdown
### 2026-08-09 [1]:微信文章正文抓取(绕过环境验证)

- **场景**:抓取 mp.weixin.qq.com 文章正文
- **方法**:`curl -sL -A "Mozilla/5.0 (iPhone; ...) Safari/604.1" <url> -o page.html`,再解析 `<div id="js_content">`(正则提取后去 HTML 标签)
- **坑**:web_fetch / 默认 UA 会命中"环境异常"验证页;r.jina.ai 代理也被拦
- **解法**:手机 UA 的 curl 直接拿到完整 HTML(约 3.5MB),`og:title` 可拿标题、`js_name` 可拿公众号名
- **可复用**:抓微信文章一律用手机 UA curl + js_content 解析;检查 `grep -c "环境异常"` 判断是否被拦
- **标签**: `微信抓取` `反爬` `curl` `HTML解析`
```

## 注意事项

- 经验笔记是**滚动记录**,不是 Wiki 文章——不追求完整结构,只求下次能用;
- 涉及敏感信息(API key、内部地址)只写"存在环境变量 X"或打码,不写真实值;
- 如果同一条经验已经整理成正式 Wiki 文章,在条目里加 `已整理 → docs/...` 指引,避免重复沉淀。
